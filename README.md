# 知识星图 xintu

**把知识点画成星空。** 每个知识点是一颗发光的星，关系是一条白色光丝；一门课、一个章节、一条定义，都在这片星海里各就其位。

支持三级结构（课程 → 章节 → 知识点）、星海 3D、局部 3D、跨层级关系线、树形大纲笔记与掌握标记。完全离线，数据只存在你自己的电脑上。

## 下载与安装

**安装包（推荐）**：下载 `知识星图-安装包-x.y.z.exe`，双击安装。

- 默认安装到 `%LOCALAPPDATA%\Programs\知识星图`，安装时可以选择其他目录；
- 只装给当前用户，不需要管理员权限；
- 安装时会检测 Microsoft WebView2 Runtime；缺少时自动联网下载并显示进度条（Windows 11 和大多数 Windows 10 已自带）；
- 可以勾选是否创建桌面快捷方式和开始菜单快捷方式；
- 卸载时会询问是否同时删除本地知识数据；选择“否”则保留，重新安装后仍可继续使用。

**绿色版**：下载整个 `app/` 文件夹，双击 `app/知识星图.exe` 直接运行，不写注册表、拷走即用。双击 `app/create-shortcut.cmd` 可以生成桌面快捷方式。

**只想试一下**：直接双击 `app/index.html`。它是一个完全离线的单文件网页，CSS、JavaScript、字体和图片都内联在里面，不需要服务器或联网；缺点是任务栏显示的是浏览器图标。

## 功能速览

### 星海：一眼看到知识全貌

整片星空就是你的知识库。课程是较大的星，章节与知识点是它周围的小星，关系线跨层级连过去。拖空白旋转、滚轮缩放、右键拖动平移；层级按钮在「一级 / 二级 / 三级 / 全部」之间切换，看全貌还是看细节随时换。

### 局部 3D：从课程下钻到知识点

双击课程或章节就进入它的局部关系图：这一门课的所有章节与知识点摊开在眼前，关系线只保留与之相关的那些。再双击章节还能继续下钻，`Esc` 逐级返回。

### 大纲笔记：一颗星里装一门课

双击任意知识点，右侧滑出详情侧栏。笔记是树形大纲：`Enter` 新建条目、`Tab` 缩进成子级、折叠展开随手点，写定义、例题、错题都行。

![侧栏笔记：选中「高中数学·函数与导数」，29 条笔记与 4 条关联](screenshots/02-notes.png)

### 掌握标记：学过的星会变金

在侧栏里勾选最底层的知识点，它在星海里就会从白色变成金色；课程与章节按下属叶子的完成比例自动聚合百分比，节点颜色随之渐变。同级连线两端都掌握才变金，上下级连线看下一级。

![掌握标记：整门课标记后侧栏显示「全课掌握 85%」，节点与标题转为金色](screenshots/03-mastery.png)

### 搜索：输入片段，直达知识点

顶部搜索框或 `Ctrl/Cmd+K`，输入标题或正文里的任意片段。结果按课程 / 章节 / 知识点分组，带命中高亮与所属路径，点一下直接跳进对应局部图并打开侧栏。

![搜索「导数」：13 条结果，含高亮、类型标签与路径](screenshots/04-search.png)

### 星河长卷：把所有笔记摊成一本书

顶部「星河长卷」把所有知识点的笔记排进同一份大文档，可以拖拽重排、跨知识点搬运、逐条编辑。复习时它比星图更像一本可以翻的书。

![星河长卷：高等数学 38 条笔记连成一篇可拖拽的长文](screenshots/05-outline.png)

## 操作

### 搜索

- 顶栏搜索框，或按 `Ctrl/Cmd+K` 聚焦；输入标题或正文里的任意片段即可，不需要完整匹配
- 搜索范围是全部课程、章节、知识点的标题和笔记正文；多个关键词用空格分开，会先找全部命中的结果，找不到时再放宽为任意一个关键词
- 结果按课程 / 章节 / 知识点列出标题、所属路径和命中片段；点击直接进入对应局部图并打开侧栏
- 搜索只读数据，不会自动创建关系线

### 星海 3D

- 拖动空白：旋转星海
- 右键拖动：平移整个知识树
- 按住节点拖动：移动节点位置（拖课程会带动它的章节）
- 单击节点：选中；单击空白：取消选中
- 双击课程 / 章节：进入局部 3D
- 滚轮：缩放
- 层级按钮：切换一级 / 二级 / 三级 / 全部
- 顶部「重置图形」：回到完整球体、清除手动拖动偏移，并切回旋转静默

### 局部 3D

- 拖动空白：旋转局部关系图
- 右键拖动：平移局部关系图
- 按住节点拖动：移动节点
- 单击空白：取消选中并关闭侧栏
- 滚轮：缩放
- 双击章节：继续下钻
- 双击知识点或课程：打开笔记侧栏
- 跨层级关系端点：直接显示名称，名称过长时以 `…` 截断，避免和邻近标签重叠
- 双击空白：在这个位置添加知识点

### 静默效果

点击顶部「静默 · 旋转」打开设置：

- 旋转 / 心跳 / 膨胀是三个独立开关，可以同时打开叠加
- 再点一次同一个效果才会关闭它；点“静止”会一次关闭全部
- 心跳：约 2 秒一拍（0.5Hz），球体轻轻收缩后回弹，同时从星海轮廓向外荡出三层错开的星辉潮汐
- 膨胀：星海持续随机向外散开、回缩；点击顶部“重置图形”可回到完整球体并切回旋转
- 速度：`1×` 到 `6×` 可调
- 静默时中心/选中节点周围会有小四芒星缓慢绕行；选中节点时关系线上有明亮的星芒脉冲
- 背景约 900 颗星（最高可调到 3 倍密度），十字星芒与低亮度星云

开关组合保存在本机，下次打开继续生效。

## 声音

点右上角 `⋯` 菜单里的「音效设置」可以直接开关声音、拖动音量（默认 87%）。全部音效由 Web Audio 实时合成，没有额外的音频文件，单文件离线打开也能用：

- 打开时的奇点蓄力与大爆炸、切换星海形状、下钻与返回、选中节点、开合侧栏、标记掌握、增删改、撤销重做、导入导出、打开菜单与弹窗都有对应的短音
- 浏览器要求先有一次点击才允许出声，所以开场先停在「点击任意处，进入星海」，点一下之后才播放开场音
- 删除知识点时，节点位置会出现一个黑洞把它吞进去，播放低频下坠与吸积盘气声
- 声音开关与音量保存在本机，下次打开继续生效

## 掌握标记

掌握复选框在右侧内容编辑区里，不显示在画布上，保持星空/3D 画面的干净。

- 双击最底层知识点打开侧栏，点击“标记为已掌握”：该知识点由白色发光变为金色发光
- 只有没有子级的叶子知识点可以打勾；课程 / 章节显示“本条及子级掌握 x%”，由叶子完成比例自动聚合
- 同级节点之间的连线：两端都掌握才变金
- 上下级之间的连线：只看更下一级，下级掌握就变金
- 课程 / 章节的侧栏会显示由下属知识点统计出的掌握百分比，画布颜色按比例从默认色渐变到掌握色
- 再次点击可取消掌握

## 设置：知识库与外观

`⋯ → 知识库路径` 和 `⋯ → 外观设置` 是两个独立窗口。

### 知识库路径

`⋯ → 知识库路径` 可以把这个知识库绑定到一个本地 JSON 文件，之后打开自动读取、修改自动写回：

- 在桌面版（`知识星图.exe`）里：点“选择知识文件”会弹出 Windows 原生文件对话框；绑定后输入框显示完整路径，之后每次保存自动写回该文件。绑定信息记在 `%LOCALAPPDATA%\KnowledgeStarmap\kb-file.txt`，重启程序会自动读取，不需要重新授权。
- 在浏览器里：Chrome / Edge 会显示“选择知识文件”，通过浏览器的文件读写授权绑定，保存自动写回；输入框只显示文件名，不显示完整路径（浏览器的安全限制）。`file://` 双击打开时，浏览器可能每次启动都收回权限，需要重新点一次“选择知识文件”。
- 不支持文件读写的环境显示“从路径载入”：按输入框里的路径读取（相对路径或 `http(s)://` 地址），只读、不写回。
- 绑定不会删除文件夹里已有的文件，也不影响导出的 JSON 数据。

演示库 `seed.json` 是构建原料，和种子模型一起放在 `packages/core/src/seed/`，构建时内联进 `app/index.html`；已经构建好的单文件不依赖它。想放自己的知识库，用 `private_knowledge_data/`（已被 `.gitignore` 忽略）或任意本地目录，再通过「知识库路径」绑定。

### 外观

`⋯ → 外观设置` 打开画质与颜色窗口：

- 全局默认节点色、掌握后颜色，点“恢复默认”还原
- 按一级课程单独覆盖默认色 / 掌握色；单门课也可以“恢复全局”
- 星空背景：星点密度、星点大小、光晕亮度、渲染倍率、像素预算、星芒闪烁与环境粒子；“恢复默认”一次还原整组
- 节点与关系线：节点亮度、节点大小、星芒大小、关系线亮度、脉冲亮度、脉冲大小六个滑杆，范围 40%–180%，拖动即时预览；星芒大小只改节点上十字星芒的尺寸，不影响节点核心与光晕；关系线亮度只改线的明暗，不改变线宽与连接关系
- 关系线未掌握时跟随节点默认色，掌握后跟随节点掌握色；跨课程同级关系线取两端平均，上下级关系线取下一级所属课程的颜色
- 颜色和五项比例都会写进知识数据，并随导出的 JSON 一起保存

## 侧栏与笔记

双击课程、章节或知识点后，右侧打开详情侧栏。

- 右上角 `⛶`：全屏编辑；再点一次退出全屏
- 右上角 `⇥`：收起侧栏
- 右缘展开按钮：重新打开
- 左边缘向左拖：拉宽侧栏，可以一直拖到整个屏幕；双击边缘复位 430px
- 笔记：树形大纲；`Enter` 新条目、`Tab` 缩进、`Shift+Tab` 反缩进、空条目 `Backspace` 删除、支持折叠与多行粘贴
- 折叠条目：点左侧小三角，或直接点整行标题展开；展开后点文字进入编辑
- 关联：章节和知识点都可以在任意层级之间建立关系线

## 星河长卷

顶部「星河长卷」会把所有知识点的笔记放进同一份大文档：

- 拖动条目左侧的小圆点：放到条目之间是移动，放到条目中间会合并为它的子级；双击圆点直接进入该条目的局部编辑
- 放到某个知识点标题或底部投放区，条目会归入该知识点
- 双击条目文字直接编辑；`Enter` 新建、`Tab` / `Shift+Tab` 调整层级
- 每个一级知识点标题左侧的三角可单独折叠/展开该知识点
- “全部折叠 / 全部展开”会连同所有一级知识点一起收起或展开

## 导入 Markdown / PDF

`⋯ → 导入 Markdown / PDF` 可以把一个或多个 `.md` / `.markdown` / `.pdf` 文件导入成知识内容：

- 只导入内容，不自动创建关系线；导入后仍由你自己连线
- 导入前可以给每个文件单独选择一级 / 二级 / 三级；二级先选一级课程，三级先选一级课程、再从该课程下选择二级章节
- 可以设置默认级别和默认上级，再一次性应用到全部文件；每个文件仍可单独改标题、级别、上级或移除
- 一级会新建课程节点；二级会插入所选课程的笔记大纲根级；三级会插入所选章节的子级
- Markdown 的标题会保留为大纲层级；PDF 按段落提取文字，扫描版 PDF 无法提取文字时会提示
- PDF 在本地解析并内联在单文件里，不上传；大文件解析时可能短暂占用页面
- 导入的正文受笔记条目长度限制，过长段落会自动拆分

## 添加、删除与撤销

- 顶部“＋ 添加知识点”：新增一个知识点
- 选中知识点后按 `Delete`：删除该节点和与它相连的关系线，会先弹窗确认
- `Ctrl+Z`：撤销；`Ctrl+Y`：重做（输入框内保留原生撤销/重做）
- `Esc`：依次关闭弹窗、侧栏、当前层级，逐级返回
- `⋯` 菜单（右上角）：导出数据、导入 Markdown / PDF、删除当前节点、知识库路径、外观设置、音效设置、打赏作者
- 删除只对当前选中的节点显示，点击后会二次确认；确认后节点位置会展开一个黑洞，把节点连同关系线一起吞掉
- 导出会打开系统保存窗口，可自己选择位置和文件名；不支持该接口的浏览器会自动下载

## 你的数据在哪里

- **桌面版**：数据保存在 `%LOCALAPPDATA%\KnowledgeStarmap\WebView2`；
- **浏览器版**：数据保存在浏览器的 `localStorage`，键名 `starmap.knowledge.v1`；两者不互通；
- **绑定知识文件后**：桌面版会记住文件完整路径，每次修改自动写回，重启后自动读取，不需要重新授权；浏览器版通过文件系统授权读写，只显示文件名；
- **备份与迁移**：`⋯ → 导出数据` 导出 JSON；换电脑时在新机器上 `⋯ → 知识库路径 → 选择知识文件` 绑定这份 JSON 即可。

## 常见问题

**数据会上传到服务器吗？**
不会。全部内容存在本机或你绑定的本地知识文件里，程序本身不联网，唯一需要联网的是安装时补装 WebView2 Runtime。

**换电脑怎么搬走？**
`⋯ → 导出数据` 存一份 JSON，拷贝到新电脑，再用 `⋯ → 知识库路径 → 选择知识文件` 绑上去。桌面版绑定后会自动读写，不需要每次手动导入。

**能删掉示例知识点吗？**
能。选中后按 `Delete` 会连带删掉它的关系线；也可以只改标题和笔记，把示例变成自己的目录。

**为什么有的知识点打不了勾？**
掌握标记只作用于最底层的叶子知识点。带子级的课程 / 章节不打勾，它们的百分比由下属叶子自动聚合。

**浏览器版每次打开都要重新选知识文件？**
`file://` 双击打开时浏览器会回收文件授权，需要重新点一次「选择知识文件」。想要免授权就用桌面版，绑定信息存在 `%LOCALAPPDATA%\KnowledgeStarmap\kb-file.txt`。

**PDF 导入后没有文字？**
扫描版 PDF 是图片，提取不到文本，程序会提示。可以先 OCR 成文字版 PDF 或 Markdown 再导入。

**能在 macOS / Linux 上用吗？**
安装包和 WebView2 壳是 Windows 专用的；但 `app/index.html` 是纯前端单文件网页，任何支持 WebGL 的现代浏览器都能直接打开。

## 开发与构建

开发模式（需要 Node.js 22+）：

```bash
npm install
npm run dev
```

构建可直接双击的单文件网页：

```bash
npm run build
```

`npm run build` 会构建 `packages/web`，把产物复制成 `app/index.html`，并附带 `app/` 里的 exe、WebView2 DLL、图标与快捷方式脚本。

重新编译 WebView2 壳程序：

```bash
powershell -File scripts/build-shell.ps1
```

生成安装包：

```bash
powershell -File scripts/build-installer.ps1
```

安装包用 [Inno Setup 6](https://jrsoftware.org/isinfo.php) 编译，编译器放在 `tools/InnoSetup6/`（已被 `.gitignore` 忽略）。脚本会读取根 `package.json` 的版本号，自动构建网页与壳程序，输出 `packaging/dist/知识星图-安装包-<版本>.exe`。

## 数据说明

- `packages/core/src/seed/seed.json` 是出厂演示库，含 10 个示例知识点（高等数学、线性代数、概率论 + 高中数学 ×3 + 高中物理 ×4）与 14 条关系，共 233 条分层笔记条目；应用默认使用构建时内联的这份数据

- JSON 是数据快照，可导入 / 导出
- “知识库路径”可以把知识库绑定到一个本地 JSON 文件（自动读写），也可以载入一个 `http(s)` 地址（只读）：exe 版由桌面壳直接读写并显示完整路径，浏览器版走文件系统授权
- `private_knowledge_data/` 是本机私有数据目录，已被 `.gitignore` 忽略，不会上传
  - `my_knowledge.json`：当前完整知识库，可在应用里通过 `⋯ → 知识库路径` 绑定或载入
  - `知识星图-*.json`：历史导出快照
