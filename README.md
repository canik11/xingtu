# 知识星图 xintu

把知识点画成星空：每个知识点是一颗发光的星，关系是一条白色光丝。支持三级结构（课程 → 章节 → 知识点）、星海 3D、局部 3D、跨层级关系与幕布式大纲笔记。

![知识星图预览](preview.png)

公开仓库只带 3 个示例知识点：高等数学、线性代数、概率论。演示库放在 `packages/core/src/seed/seed.json`，可以通过「知识库路径」换成你自己的知识库。你自己的完整知识库只保存在本机；本机私有的 JSON 数据放在 `private_knowledge_data/`，该目录已被 `.gitignore` 忽略，不会进入公开仓库。`app/index.html` 是构建好的单文件版本，随仓库一起提交，下载后双击即可试用。

## 运行

开发模式（需要 Node.js 22+）：

```bash
npm install
npm run dev
```

构建可直接双击的单文件网页：

```bash
npm run build
```

构建会生成 `dist/`，并复制成 `app/index.html`。之后双击：

```text
app/index.html
```

不需要服务器或联网，CSS 和 JavaScript 都打包在这一个 HTML 文件里。渲染默认使用 WebGL（PixiJS）；不支持 WebGL 的浏览器会自动回退到 Canvas 2D。WebGL 渲染倍率最高与 3D 视图最大缩放一致（3×，受约 1200 万像素/帧预算保护），文字标签使用同一倍率，避免放大后发虚或出现锯齿。

## 把它当成真正的小应用

`app/` 里带一个自绘窗口的「知识星图.exe」：

- 双击 `app/知识星图.exe` 直接打开，任务栏显示星图图标，而不是浏览器图标（窗口用 WebView2 加载同目录的 `index.html`，没有地址栏和标签页）；
- 首次运行需要 Microsoft Edge WebView2 Runtime。Windows 11 和大多数 Windows 10 已自带；缺失时程序会弹提示，可从微软官网免费安装；
- 双击 `app/create-shortcut.cmd` 会在桌面生成「知识星图」快捷方式：有 exe 时优先用 exe，没有 exe 时才退回 Edge / Chrome 的 `--app` 模式；
- 想放到开始菜单：`create-shortcut.ps1 -Place startmenu`；
- 需要重新编译 exe 时运行 `scripts/build-shell.ps1`（调用系统自带 csc，依赖 `packaging/webview2/` 里的 WebView2 DLL）。

注意：exe 版的数据存在 `%LOCALAPPDATA%\KnowledgeStarmap\WebView2`，与 Edge 浏览器里的 localStorage 不是同一份。如果你之前在浏览器 --app 窗口里录入过内容，先在旧窗口「导出数据」，再到 exe 里用「知识库路径 → 选择知识文件」导入。exe 版绑定知识文件后会记住完整路径，之后自动读取、自动写回，重启不需要重新授权。

分发时把整个 `app/` 文件夹打包发给对方（exe、3 个 DLL、`index.html`、图标和快捷方式脚本），对方双击 `create-shortcut.cmd` 即可。快捷方式记录的是绝对路径，换电脑或换文件夹后需要重新运行一次脚本。只想发一个 HTML 也可以：直接发 `app/index.html`，双击仍能离线使用，只是任务栏会显示浏览器的图标。

## 操作

### 搜索

- 顶栏搜索框，或按 `Ctrl/Cmd+K` 聚焦；输入标题或正文里的任意片段即可，不需要完整匹配
- 搜索范围是全部课程、章节、知识点的标题和笔记正文；多个关键词用空格分开，会先找全部命中的结果，找不到时再放宽为任意一个关键词
- 结果按课程 / 章节 / 知识点列出标题、所属路径和命中片段；点击直接进入对应局部图并打开侧栏
- 搜索只读数据，不会自动创建关系线

### 星海 3D

- 拖动空白：旋转星海
- 右键拖动：平移整个知识树
- 按住节点拖动：移动节点位置（拖课程会带动它的章节）
- 单击节点：选中；单击空白：取消选中
- 双击课程 / 章节：进入局部 3D
- 滚轮：缩放
- 层级按钮：切换一级 / 二级 / 三级
- 重置球形：回到完整球体、清除手动拖动偏移，并切回旋转静默

### 局部 3D

- 拖动空白：旋转局部关系图
- 右键拖动：平移局部关系图
- 按住节点拖动：移动节点
- 单击空白：取消选中并关闭侧栏
- 滚轮：缩放
- 双击章节：继续下钻
- 双击知识点或课程：打开笔记侧栏
- 跨层级关系端点：直接显示名称，名称过长时以 `…` 截断，避免和邻近标签重叠
- 双击空白：在这个位置添加知识点

### 静默效果

点击顶部“静默 · 旋转”打开设置：

- 旋转 / 心跳 / 膨胀是三个独立开关，可以同时打开叠加
- 再点一次同一个效果才会关闭它；点“静止”会一次关闭全部
- 心跳：约 2.4 秒一拍，球体只有 2~3% 的轻微收缩（主拍后跟一下更轻的次拍），节点光晕、关系线与背景星点同时微微亮起，再有一圈细碎星光从星海轮廓荡出去
- 膨胀：星海持续随机向外散开、回缩；点击顶部“重置球形”可回到完整球体并切回旋转
- 速度：`1×` 到 `6×` 可调
- 静默时中心/选中节点周围会有小四芒星缓慢绕行；选中节点时关系线上有明亮的星芒脉冲
- 背景约 900 颗星、十字星芒与低亮度星云

开关组合保存在本机，下次打开继续生效。

## 掌握标记

掌握复选框在右侧内容编辑区里，不显示在画布上，保持星空/3D 画面的干净。

- 双击三级知识点打开侧栏，点击“标记为已掌握”：该知识点由白色发光变为金色发光
- 同级节点之间的连线：两端都掌握才变金
- 上下级之间的连线：只看更下一级，下级掌握就变金
- 课程 / 章节的侧栏会显示由下属知识点统计出的掌握百分比，画布颜色按比例从默认色渐变到掌握色
- 再次点击可取消掌握

## 设置：知识库与外观

`⋯ → 知识库路径` 和 `⋯ → 外观设置` 是两个独立窗口。

### 知识库路径

`⋯ → 知识库路径` 可以把这个知识库绑定到一个本地 JSON 文件，之后打开自动读取、修改自动写回：

- 在桌面版（`知识星图.exe`）里：点“选择知识文件”会弹出 Windows 原生文件对话框；绑定后输入框显示完整路径，之后每次保存自动写回该文件。绑定信息记在 `%LOCALAPPDATA%\KnowledgeStarmap\kb-file.txt`，重启程序会自动读取，不需要重新授权。
- 在浏览器里：Chrome / Edge 会显示“选择知识文件”，通过浏览器的文件读写授权绑定，保存自动写回；输入框只显示文件名，不显示完整路径（浏览器的安全限制）。`file://` 双击打开时，浏览器可能每次启动都收回权限，需要重新点一次“选择知识文件”。
- 不支持文件读写的环境显示“从路径载入”：按输入框里的路径读取（相对路径或 `http(s)://` 地址），只读、不写回。
- 绑定不会删除文件夹里已有的文件，也不影响导出的 JSON 数据。

演示库 `seed.json` 是构建原料，和种子模型一起放在 `packages/core/src/seed/`，构建时内联进 `app/index.html`；已经构建好的单文件不依赖它。想放自己的知识库，用 `private_knowledge_data/`（已被 `.gitignore` 忽略）或任意本地目录，再通过「知识库路径」绑定。

### 外观

`⋯ → 外观设置` 打开画质与颜色窗口：

- 全局默认节点色、掌握后颜色，点“恢复默认”还原
- 按一级课程单独覆盖默认色 / 掌握色；单门课也可以“恢复全局”
- 星空背景：星点密度、星点大小、光晕亮度同时作用于 3D 星海和 2D 星图；3D 星海另有渲染倍率、像素预算、星芒闪烁与环境粒子，2D 星图另有渲染倍率与星点间距；“恢复默认”一次还原整组
- 节点与关系线：节点亮度、节点大小、关系线亮度、脉冲亮度、脉冲大小五个滑杆，范围 40%–180%，拖动即时预览；关系线亮度只改线的明暗，不改变线宽与连接关系
- 2D 星图按“节点为主、关系线为辅”重新排布了样式：节点半径与光晕更大、带完整星芒，关系线更细更暗并在节点边缘内缩，节点下方的暗盘会压住穿过的线，密集连线下也能一眼看清节点
- 关系线未掌握时跟随节点默认色，掌握后跟随节点掌握色；跨课程同级关系线取两端平均，上下级关系线取下一级所属课程的颜色
- 颜色和五项比例都会写进知识数据，并随导出的 JSON 一起保存

## 侧栏与笔记

双击课程、章节或知识点后，右侧打开详情侧栏。

- 右上角 `⛶`：全屏编辑；再点一次退出全屏
- 右上角 `⇥`：收起侧栏
- 右缘展开按钮：重新打开
- 左边缘向左拖：拉宽侧栏，可以一直拖到整个屏幕；双击边缘复位 430px
- 笔记：幕布式大纲；`Enter` 新条目、`Tab` 缩进、`Shift+Tab` 反缩进、空条目 `Backspace` 删除、支持折叠与多行粘贴
- 折叠条目：点左侧小三角，或直接点整行标题展开；展开后点文字进入编辑
- 关联：章节和知识点都可以在任意层级之间建立关系线

## 全项目大纲

`⋯ → 全项目大纲` 会把所有知识点的笔记放进同一份大文档：

- 拖动条目左侧的小圆点：放到条目之间是移动，放到条目中间会合并为它的子级
- 放到某个知识点标题或底部投放区，条目会归入该知识点
- 双击条目文字直接编辑；`Enter` 新建、`Tab` / `Shift+Tab` 调整层级
- 每个一级知识点标题左侧的三角可单独折叠/展开该知识点
- “全部折叠 / 全部展开”会连同所有一级知识点一起收起或展开

## 导入 Markdown / PDF

`⋯ → 导入 Markdown / PDF` 可以把一个或多个 `.md` / `.markdown` / `.pdf` 文件导入成知识内容：

- 只导入内容，不自动创建关系线；导入后仍由你自己连线
- 导入前可以给每个文件单独选择一级 / 二级 / 三级；二级先选一级课程，三级先选一级课程、再从该课程下选择二级章节
- 可以设置默认级别和默认上级，再一次性应用到全部文件；每个文件仍可单独改标题、级别、上级或移除
- 一级会新建课程节点；二级会插入所选课程的笔记大纲根级；三级会插入所选章节的子级
- Markdown 的标题会保留为大纲层级；PDF 按段落提取文字，扫描版 PDF 无法提取文字时会提示
- PDF 在本地解析并内联在单文件里，不上传；大文件解析时可能短暂占用页面
- 导入的正文受笔记条目长度限制，过长段落会自动拆分

## 添加与数据

- 顶部“＋ 添加知识点”：新增一个知识点
- `Esc`：依次关闭弹窗、侧栏、当前层级，逐级返回
- `⋯` 菜单：导入 Markdown / PDF、导入 JSON 数据、导出 JSON、删除当前节点、设置、全项目大纲、重新布局、重置视图、恢复初始知识库
- 删除只对当前选中的课程节点显示，点击后会二次确认
- 导出会打开系统保存窗口，可自己选择位置和文件名；不支持该接口的浏览器会自动下载

网页版数据保存在浏览器 `localStorage`，键名 `starmap.knowledge.v1`。想长期保存或换设备，请用 `⋯ → 导出数据` 备份 JSON。

## 数据说明

- `packages/core/src/seed/seed.json` 是出厂演示库，只含 3 个示例知识点；应用默认使用构建时内联的这份数据
- `localStorage` 是浏览器里的实时数据库，键名 `starmap.knowledge.v1`
- JSON 是数据快照，可导入 / 导出
- “知识库路径”可以把知识库绑定到一个本地 JSON 文件（自动读写），也可以载入一个 `http(s)` 地址（只读）：exe 版由桌面壳直接读写并显示完整路径，浏览器版走文件系统授权
- `private_knowledge_data/` 是本机私有数据目录，已被 `.gitignore` 忽略，不会上传
  - `my_knowledge.json`：当前完整知识库，可在应用里通过 `⋯ → 知识库路径` 绑定或载入
  - `知识星图-*.json`：历史导出快照
- “恢复初始知识库”会重新使用内置演示库（来自 `packages/core/src/seed/seed.json`）
