# 知识星图 xintu

把知识点画成星空：每个知识点是一颗发光的星，关系是一条白色光丝。支持三级结构（课程 → 章节 → 知识点）、星海 3D、局部 3D、跨层级关系与幕布式大纲笔记。

![知识星图预览](preview.png)

公开仓库只带 3 个示例知识点：高等数学、线性代数、概率论。演示库放在 `knowledge/seed.json`，也可以换成你自己的知识库。你自己的完整知识库只保存在本机；本机私有的 JSON 数据放在 `private_knowledge_data/`，该目录已被 `.gitignore` 忽略，不会进入公开仓库。`app/index.html` 是构建好的单文件版本，随仓库一起提交，下载后双击即可试用。

## 运行

开发模式（需要 Node.js 22+）：

```bash
npm install
npm run dev
```

构建可直接双击的单文件网页：

```bash
npm run build
```

构建会生成 `dist/`，并复制成 `app/index.html`。之后双击：

```text
app/index.html
```

不需要服务器或联网，CSS 和 JavaScript 都打包在这一个 HTML 文件里。渲染默认使用 WebGL（PixiJS）；不支持 WebGL 的浏览器会自动回退到 Canvas 2D。WebGL 渲染倍率最高与 3D 视图最大缩放一致（2.8×，受约 1200 万像素/帧预算保护），文字标签使用同一倍率，避免放大后发虚或出现锯齿。

## 把它当成小应用

`app/` 里除了 `index.html`，还带了一枚图标 `xintu.ico` 和快捷方式脚本：

- 双击 `app/create-shortcut.cmd`（或用 PowerShell 运行 `create-shortcut.ps1`），会在桌面生成「知识星图」快捷方式；
- 快捷方式用 Edge / Chrome 的 `--app` 模式打开，没有地址栏和标签页，看起来像一个独立小应用，图标就是星图图标；
- 想放到开始菜单：`create-shortcut.ps1 -Place startmenu`；想指定浏览器：`-Browser chrome`；找不到 Edge/Chrome 时会退回系统默认浏览器。

图标由 `scripts/make-icon.py`（Pillow）生成，重新运行即可更新 `assets/xintu.png` 与 `assets/xintu.ico`。

分发时把整个 `app/` 文件夹打包发给对方，对方双击一次 `create-shortcut.cmd` 生成自己的快捷方式。快捷方式记录的是绝对路径，所以换电脑或换文件夹后需要重新运行一次脚本。

## 操作

### 搜索

- 顶栏搜索框，或按 `Ctrl/Cmd+K` 聚焦；输入标题或正文里的任意片段即可，不需要完整匹配
- 搜索范围是全部课程、章节、知识点的标题和笔记正文；多个关键词用空格分开，会先找全部命中的结果，找不到时再放宽为任意一个关键词
- 结果按课程 / 章节 / 知识点列出标题、所属路径和命中片段；点击直接进入对应局部图并打开侧栏
- 搜索只读数据，不会自动创建关系线

### 星海 3D

- 拖动空白：旋转星海
- 右键拖动：平移整个知识树
- 按住节点拖动：移动节点位置（拖课程会带动它的章节）
- 单击节点：选中；单击空白：取消选中
- 双击课程 / 章节：进入局部 3D
- 滚轮：缩放
- 层级按钮：切换一级 / 二级 / 三级
- 重置球形：回到完整球体、清除手动拖动偏移，并切回旋转静默

### 局部 3D

- 拖动空白：旋转局部关系图
- 右键拖动：平移局部关系图
- 按住节点拖动：移动节点
- 单击空白：取消选中并关闭侧栏
- 滚轮：缩放
- 双击章节：继续下钻
- 双击知识点或课程：打开笔记侧栏
- 跨层级关系端点：直接显示名称，名称过长时以 `…` 截断，避免和邻近标签重叠
- 双击空白：在这个位置添加知识点

### 静默效果

点击顶部“静默 · 旋转”打开设置：

- 旋转 / 呼吸 / 膨胀是三个独立开关，可以同时打开叠加
- 再点一次同一个效果才会关闭它；点“静止”会一次关闭全部
- 膨胀：星海持续随机向外散开、回缩；点击顶部“重置球形”可回到完整球体并切回旋转
- 速度：`1×` 到 `6×` 可调
- 静默时中心/选中节点周围会有小四芒星缓慢绕行；选中节点时关系线上有明亮的星芒脉冲
- 背景约 900 颗星、十字星芒与低亮度星云

开关组合保存在本机，下次打开继续生效。

## 掌握标记

掌握复选框在右侧内容编辑区里，不显示在画布上，保持星空/3D 画面的干净。

- 双击三级知识点打开侧栏，点击“标记为已掌握”：该知识点由白色发光变为金色发光
- 同级节点之间的连线：两端都掌握才变金
- 上下级之间的连线：只看更下一级，下级掌握就变金
- 课程 / 章节的侧栏会显示由下属知识点统计出的掌握百分比，画布颜色按比例从默认色渐变到掌握色
- 再次点击可取消掌握

## 设置：知识库与外观

`⋯ → 知识库路径` 和 `⋯ → 外观设置` 是两个独立窗口。

### 知识库路径

`⋯ → 知识库路径` 可以把这个知识库绑定到一个本地 JSON 文件，之后打开自动读取、修改自动写回：

- 按钮会根据运行环境自动选择方式：
  - 浏览器支持文件读写（Chrome / Edge 等）时显示“选择知识文件”：选一个 JSON 绑定，浏览器会请求一次读写授权，之后保存自动写回该文件
  - 不支持文件读写的环境显示“从路径载入”：按输入框里的路径读取（`knowledge/seed.json` 这类相对路径或 `http(s)://` 地址），只读、不写回
- 输入框里填了非默认路径时，按钮会按该路径载入
- 绑定信息只保存在本机（文件句柄存在 IndexedDB，路径存在 `localStorage`），不影响导出的 JSON 数据；不会删除文件夹里已有的文件

> 提示：`file://` 双击打开时，浏览器对本地文件的授权行为因版本而异；如果选择文件后刷新需要重新授权，重新点一次“选择知识文件”即可。

`knowledge/` 是放知识库 JSON 的地方，`seed.json` 是出厂演示库。注意：这个文件夹里的 `.json` 默认会被 git 跟踪，私人知识库不要直接提交。

### 外观

`⋯ → 外观设置` 打开画质与颜色窗口：

- 全局默认节点色、掌握后颜色，点“恢复默认”还原
- 按一级课程单独覆盖默认色 / 掌握色；单门课也可以“恢复全局”
- 节点亮度、节点大小、关系线脉冲亮度、脉冲大小四个滑杆，范围 40%–180%，拖动即时预览
- 关系线未掌握时跟随节点默认色，掌握后跟随节点掌握色；跨课程同级关系线取两端平均，上下级关系线取下一级所属课程的颜色
- 颜色和四项比例都会写进知识数据，并随导出的 JSON 一起保存

## 侧栏与笔记

双击课程、章节或知识点后，右侧打开详情侧栏。

- 右上角 `⛶`：全屏编辑；再点一次退出全屏
- 右上角 `⇥`：收起侧栏
- 右缘展开按钮：重新打开
- 左边缘向左拖：拉宽侧栏，可以一直拖到整个屏幕；双击边缘复位 430px
- 笔记：幕布式大纲；`Enter` 新条目、`Tab` 缩进、`Shift+Tab` 反缩进、空条目 `Backspace` 删除、支持折叠与多行粘贴
- 折叠条目：点左侧小三角，或直接点整行标题展开；展开后点文字进入编辑
- 关联：章节和知识点都可以在任意层级之间建立关系线

## 全项目大纲

`⋯ → 全项目大纲` 会把所有知识点的笔记放进同一份大文档：

- 拖动条目左侧的小圆点：放到条目之间是移动，放到条目中间会合并为它的子级
- 放到某个知识点标题或底部投放区，条目会归入该知识点
- 双击条目文字直接编辑；`Enter` 新建、`Tab` / `Shift+Tab` 调整层级
- 每个一级知识点标题左侧的三角可单独折叠/展开该知识点
- “全部折叠 / 全部展开”会连同所有一级知识点一起收起或展开

## 导入 Markdown / PDF

`⋯ → 导入 Markdown / PDF` 可以把一个或多个 `.md` / `.markdown` / `.pdf` 文件导入成知识内容：

- 只导入内容，不自动创建关系线；导入后仍由你自己连线
- 导入前可以给每个文件单独选择一级 / 二级 / 三级；二级先选一级课程，三级先选一级课程、再从该课程下选择二级章节
- 可以设置默认级别和默认上级，再一次性应用到全部文件；每个文件仍可单独改标题、级别、上级或移除
- 一级会新建课程节点；二级会插入所选课程的笔记大纲根级；三级会插入所选章节的子级
- Markdown 的标题会保留为大纲层级；PDF 按段落提取文字，扫描版 PDF 无法提取文字时会提示
- PDF 在本地解析并内联在单文件里，不上传；大文件解析时可能短暂占用页面
- 导入的正文受笔记条目长度限制，过长段落会自动拆分

## 添加与数据

- 顶部“＋ 添加知识点”：新增一个知识点
- `Esc`：依次关闭弹窗、侧栏、当前层级，逐级返回
- `⋯` 菜单：导入 Markdown / PDF、导入 JSON 数据、导出 JSON、删除当前节点、设置、全项目大纲、重新布局、重置视图、恢复初始知识库
- 删除只对当前选中的课程节点显示，点击后会二次确认
- 导出会打开系统保存窗口，可自己选择位置和文件名；不支持该接口的浏览器会自动下载

网页版数据保存在浏览器 `localStorage`，键名 `starmap.knowledge.v1`。想长期保存或换设备，请用 `⋯ → 导出数据` 备份 JSON。

## 数据说明

- `knowledge/seed.json` 是出厂演示库，只含 3 个示例知识点；应用默认从这里读取
- `localStorage` 是浏览器里的实时数据库，键名 `starmap.knowledge.v1`
- JSON 是数据快照，可导入 / 导出
- “知识库路径”可以把知识库绑定到一个本地 JSON 文件（自动读写），也可以载入一个 `http(s)` 地址（只读）
- `private_knowledge_data/` 是本机私有数据目录，已被 `.gitignore` 忽略，不会上传
  - `my_knowledge.json`：当前完整知识库，可在应用里通过 `⋯ → 知识库路径` 绑定或载入
  - `知识星图-*.json`：历史导出快照
- “恢复初始知识库”会重新使用 `knowledge/seed.json` 里的演示库
